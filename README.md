# Tic Tac Toe
**Description:** This project took a few years for me to figure out. I started coding it back in 2022, but it always had an issue with the logic of how the computer plays. Occasionally it wouldn't play at all, other times it would play twice in a turn. Finally, after 4 years, I believe it has been perfected logically and functionally. It may not be written the correct way, but that's because I wrote it, and rewrote it, and rewrote it, and in our line of work, if it works, don't touch it!
